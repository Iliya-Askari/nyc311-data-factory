# NYC 311 Data Factory (Stage 1)

The `nyc311_factory` Python package provides batch-based, resumable ingestion of NYC 311 complaints, contract-based validation and quarantine, data cleaning, integration with U.S. Census population data, and generation of a case-level dataset, a wide-format table, and a `run_manifest.json` file.

## Run from a Clean Directory (One Command)

```bash
./run_all.sh          # Linux/macOS
run_all.bat            # Windows
```

This command creates a virtual environment, installs pinned dependencies, runs the tests, and executes the entire data factory pipeline.

Outputs are saved in `data/curated/`, including the datasets, wide-format table, quarantined records, data quality report, and `run_manifest.json`.

## Commands

```bash
pip install -r requirements.txt && pip install -e .

nyc311 run                  # Run the entire pipeline
nyc311 fetch                # Fetch data only (resumable)
nyc311 curate               # Clean data and generate outputs only

nyc311 --mode moving run    # Process data from the last run through today

nyc311 --max-batches 2 run  # Stop fetching after 2 batches;
                            # rerunning resumes from where it stopped
```

Configuration settings, including the date range, batch size, file paths, retry count, quarantine threshold, and agency scope, are defined in `config/default.json`.

API tokens must be provided through environment variables and must never be committed to Git:

- `NYC311_APP_TOKEN` — Optional; used to access the Socrata API quota.
- `CENSUS_API_KEY` — Census API key.

## Exit Codes

- `0` — Success
- `2` — Configuration error
- `3` — Network error
- `4` — API schema change
- `5` — Validation error
- `6` — Quarantine threshold exceeded
- `7` — Insufficient data
- `8` — Incomplete data ingestion; complete the fetch stage first

## Tests (Offline)

```bash
python -m unittest discover -s tests -t .
```

## Jupyter Notebook

```bash
jupyter nbconvert --to notebook --execute --inplace solution.ipynb
```

Saved outputs must be generated by running the notebook against real data.

To run the pipeline offline using **synthetic data** for demonstration purposes only:

```bash
python scripts/make_demo_data.py && NYC311_CONFIG=config/demo.json nyc311 --config config/demo.json run
```

## Project Structure

- `src/nyc311_factory/` — Source code
- `tests/` — Tests
- `config/` — Configuration files
- `docs/data_contract.md` — Data contract and policies
- `data/raw/` — Raw data (excluded from Git)
- `data/curated/` — Processed outputs
